JavaScript Arcade

HTML, CSS, JavaScript 미션을 플레이하는 작은 오락실입니다.

수업 예제를 버튼, 점수판, 타이머가 있는 미니게임처럼 바꾸었습니다. 간단한 코드를 직접 조작하며 결과를 바로 확인할 수 있습니다.

  1. Stage 01

    랜덤 퀴즈 머신

    HTML, CSS, JavaScript 중 하나를 랜덤으로 뽑고, 선택된 주제의 퀴즈를 풀어 점수를 올립니다.

    Rule
    주제와 문제가 무작위로 등장하고, 정답 선택 시 점수가 올라갑니다.
    Code
    Array, Math.random, event listener, DOM update 사용
    TOPIC READY SCORE 0 / 0
    버튼을 눌러 퀴즈를 시작하세요.
    HTML, CSS, JavaScript 중 하나가 랜덤으로 출제됩니다.

  2. Stage 02

    D-Day 타이머

    목표 날짜를 입력하면 남은 시간을 계산해 다음 스테이지까지의 카운트다운처럼 보여줍니다.

    Rule
    두 날짜의 시간 차이를 일 단위로 변환할 수 있다.
    Code
    Date 객체, millisecond 차이, Math.ceil 사용
    목표 날짜를 선택해 주세요.

  3. Stage 03

    DOM 스타일 매칭 배틀

    오른쪽 정답 화면을 보고 왼쪽 화면을 같은 모양으로 맞춥니다. 맞으면 PERFECT, 빗나가면 MISS가 표시됩니다.

    Rule
    이벤트 리스너를 통해 화면 요소의 스타일을 직접 변경할 수 있다.
    Code
    click event, style property, display toggle 사용
    진행 0 / 4 시간 0.0초 게임 시작을 눌러주세요.

    내 화면

    웹 개발자 윤정훈

  4. Stage 04

    피자 주문 미션

    메뉴 선택과 수량 변경 이벤트를 사용해 주문 금액을 실시간으로 계산합니다.

    Rule
    메뉴를 하나 이상 선택하고 배달 주소를 입력합니다.
    Code
    change event, submit event, checkbox, number input 사용
    주문 합계 0원
    메뉴를 골라 주문 미션을 시작하세요.

  5. Stage 05

    탄막 피하기 드라이브

    방향키로 자동차를 움직이며 오른쪽에서 날아오는 탄막을 피하고, 몇 초 동안 살아남는지 기록합니다.

    Rule
    탄막에 닿지 않고 오래 버틸수록 기록이 올라갑니다.
    Code
    keydown event, setInterval, Math.random, collision check 사용
